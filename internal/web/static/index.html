1. Anatomia das Bases de Notificação Espontânea

A farmacovigilância pós-comercialização opera fundamentalmente sobre Sistemas de Notificação Espontânea (SRS - Spontaneous Reporting Systems). Ao contrário de ensaios clínicos randomizados (RCTs), estas bases são observacionais, descentralizadas e não possuem coortes pré-definidas.

  • FDA FAERS (EUA / Global): Mantido pelo US Food and Drug Administration. Abrange mais de 25 milhões de relatos desde 1968, com envios diretos (pacientes/médicos via MedWatch) e mandatórios (indústrias detentoras de registro). Acesso via API REST aberta e indexada em Elasticsearch.
  • ANVISA VigiMed (Brasil): Sistema oficial do Brasil adotado em dez/2018 para medicamentos e vacinas, baseado no software VigiFlow do Uppsala Monitoring Centre (UMC/OMS) e no padrão ICH E2B(R3), regulamentado pela RDC nº 406/2020 e RDC nº 967/2025.
  • WHO VigiBase (Global - UMC/OMS): O maior repositório de segurança farmacológica do planeta (+35M relatos de >130 países). Acesso público agregado via VigiAccess.org.
  • EMA EudraVigilance (União Europeia): Repositório da Agência Europeia de Medicamentos para os 27 estados-membros, acessível publicamente para relatórios agregados em adrreports.eu.
  • Canada Vigilance (Health Canada): Base aberta canadense distribuída em arquivos ASCII estruturados via Open Data Canada.

2. Formulação Matemática e Métricas de Desproporcionalidade

Para cada par Fármaco ($D$) × Evento Adverso ($E$), decompõe-se a população de relatos em uma matriz de contingência $2 \times 2$ contra o universo total ($N$):

Evento Alvo ($E$) Outros Eventos ($\neg E$) Total Margem
Fármaco Alvo ($D$) a b a + b
Outros Fármacos ($\neg D$) c d c + d
Total Margem a + c b + d N = a + b + c + d

A. Proportional Reporting Ratio (PRR - Evans et al., 2001):

PRR = [a / (a + b)] / [c / (c + d)]
SE(ln PRR) = √[1/a - 1/(a+b) + 1/c - 1/(c+d)]
CI_95%(PRR) = [exp(ln PRR - 1.96 × SE), exp(ln PRR + 1.96 × SE)]

B. Reporting Odds Ratio (ROR - van Puijenbroek et al., 2002; Rothman et al., 2004):

ROR = (a × d) / (b × c)
SE(ln ROR) = √[1/a + 1/b + 1/c + 1/d]
CI_95%(ROR) = [exp(ln ROR - 1.96 × SE), exp(ln ROR + 1.96 × SE)]

Correção de Haldane-Anscombe: Se qualquer célula da matriz $2 \times 2$ for nula ($a, b, c, d = 0$), adiciona-se $+0.5$ a todas as quatro células para estabilizar o cálculo logarítmico e prevenir divisões por zero.

C. Chi-Quadrado com Correção de Continuidade de Yates (χ²):

χ²_Yates = N × (max(0, |a×d - b×c| - N/2))² / [(a+b)(c+d)(a+c)(b+d)]

D. Critérios Decisórios Regulatórios (Evans / EMA GVP Module IX):

  • Sinal Ativo / Emergente: $a \ge 3$, $\text{PRR} \ge 2.0$, e $\chi^2_{\text{Yates}} \ge 4.0$ ($p < 0.0455$).
  • Sinal Potencial: $a \ge 3$ e ($\text{PRR} \ge 1.5$ ou limite inferior do $\text{IC}_{95\%}(\text{ROR}) > 1.0$).

6. Guia Prático "Faça Você Mesmo" (DIY) para Pesquisadores

Qualquer pesquisador pode reproduzir as métricas de desproporcionalidade de forma 100% independente executando consultas diretas aos repositórios governamentais.

A. Consulta Direta à API openFDA (cURL / Terminal):

curl "https://api.fda.gov/drug/event.json?search=_exists_:patient.reaction.reactionmeddrapt&limit=1"

# 2. Total de relatos do Fármaco (a + b)
curl "https://api.fda.gov/drug/event.json?search=patient.drug.openfda.generic_name:\"SEMAGLUTIDE\"&limit=1"

# 3. Top reações adversas do Fármaco (termos MedDRA PT)
curl "https://api.fda.gov/drug/event.json?search=patient.drug.openfda.generic_name:\"SEMAGLUTIDE\"&count=patient.reaction.reactionmeddrapt.exact&limit=10"

B. Script de Reprodução Automatizada em Python (Requests + SciPy):

import math

def calc_disproportionality(a, drug_total, rx_total, n_universe):
    b = drug_total - a
    c = rx_total - a
    d = n_universe - (a + b + c)
    # Haldane-Anscombe continuity correction if any cell is 0
    adj = 0.5 if (a == 0 or b == 0 or c == 0 or d == 0) else 0.0
    A, B, C, D = a + adj, b + adj, c + adj, d + adj

    # PRR calculation
    prr = (A / (A + B)) / (C / (C + D))
    se_prr = math.sqrt(1/A - 1/(A+B) + 1/C - 1/(C+D))
    prr_ci = (math.exp(math.log(prr) - 1.96 * se_prr), math.exp(math.log(prr) + 1.96 * se_prr))

    # ROR calculation
    ror = (A * D) / (B * C)
    se_ror = math.sqrt(1/A + 1/B + 1/C + 1/D)
    ror_ci = (math.exp(math.log(ror) - 1.96 * se_ror), math.exp(math.log(ror) + 1.96 * se_ror))

    # Yates' Chi-Square
    num = max(0, abs(a*d - b*c) - n_universe / 2.0)**2
    den = (a + b) * (c + d) * (a + c) * (b + d)
    chi2_yates = (n_universe * num) / den if den > 0 else 0.0

    is_signal = (a >= 3 and prr >= 2.0 and chi2_yates >= 4.0)
    return {"PRR": prr, "PRR_CI": prr_ci, "ROR": ror, "ROR_CI": ror_ci, "Chi2": chi2_yates, "ActiveSignal": is_signal}

# Exemplo: Semaglutida e Pancreatite (a=1420, a+b=58320, a+c=89400, N=26145890)
print(calc_disproportionality(1420, 58320, 89400, 26145890))

C. Script de Reprodução em R:

calc_pv_signal <- function(a, drug_total, rx_total, n_universe) {
  b <- drug_total - a
  c <- rx_total - a
  d <- n_universe - (a + b + c)
  adj <- ifelse(a==0 | b==0 | c==0 | d==0, 0.5, 0)
  A <- a + adj; B <- b + adj; C <- c + adj; D <- d + adj

  prr <- (A / (A + B)) / (C / (C + D))
  se_prr <- sqrt(1/A - 1/(A+B) + 1/C - 1/(C+D))
  prr_ci <- exp(log(prr) + c(-1.96, 1.96) * se_prr)

  ror <- (A * D) / (B * C)
  se_ror <- sqrt(1/A + 1/B + 1/C + 1/D)
  ror_ci <- exp(log(ror) + c(-1.96, 1.96) * se_ror)

  chi2 <- (n_universe * (max(0, abs(a*d - b*c) - n_universe/2))^2) / ((a+b)*(c+d)*(a+c)*(b+d))
  return(list(PRR=prr, PRR_CI95=prr_ci, ROR=ror, ROR_CI95=ror_ci, Chi2_Yates=chi2, Signal=(a>=3 & prr>=2 & chi2>=4)))
}

7. Vieses Estruturais e Limitações Metodológicas

  • Ausência de Denominador Prescricional: Notificações espontâneas quantificam proporções de reporte, jamais incidência na população geral. O número de pacientes em uso do fármaco no mundo não consta nos bancos de SRS.
  • Efeito Weber & Notoriedade Mediática: Picos de reporte ocorrem nos primeiros 2 anos após a introdução no mercado ou após veiculação em jornais e redes sociais. Isso inflaciona a desproporcionalidade matemática sem que a toxicidade biológica tenha sofrido alteração.
  • Não-Causalidade: A detecção de um sinal estatístico ($\text{PRR} \ge 2.0$, $\chi^2 \ge 4.0$) é estritamente um instrumento de triagem e geração de hipóteses para posterior avaliação em estudos analíticos de coorte ou caso-controle. Não constitui prova de causalidade farmacológica.

Limitação metodológica: os cálculos usam relatos espontâneos do FAERS. Coocorrência no relato não vincula individualmente um medicamento à reação, não comprova causalidade e não estima incidência clínica.
Metodologia estatística e formulação

A triagem avalia se uma reação é relatada proporcionalmente mais para o medicamento-alvo do que no background dos demais relatos. Isso prioriza hipóteses para revisão; não estabelece uma conclusão de segurança.

1. Proportional Reporting Ratio (PRR)

Compara a proporção de relatos da reação para o medicamento de interesse com a proporção no background.

PRR = [a / (a + b)] / [c / (c + d)]

Limiar configurado de triagem: PRR ≥ 2,0, a ≥ 3 e χ² ≥ 4,0.

2. Reporting Odds Ratio (ROR)

Compara as odds de relatar o evento com o medicamento-alvo e com os demais medicamentos.

ROR = (a × d) / (b × c)

Os intervalos de confiança usam variância assintótica com correção de Haldane-Anscombe quando há célula zero.

3. Qui-quadrado corrigido de Yates

Estatística de continuidade para uma tabela 2 × 2 com um grau de liberdade.

χ² = N(max(0, |ad − bc| − N/2))² / [(a+b)(c+d)(a+c)(b+d)]
